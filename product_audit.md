# Auditoría de expansión de Cuidar Conecta

La versión actual ya articula una propuesta institucional clara, un lenguaje responsable, una identidad editorial reconocible y un circuito funcional para solicitudes. Su siguiente evolución debe consolidar el paso de **página institucional** a **plataforma de relación institucional**, sin desviar el propósito hacia una aplicación clínica ni sobrecargar la primera visita.

| Dimensión | Base actual | Ampliación prioritaria |
| --- | --- | --- |
| Marca | Paleta, tipografía editorial y una cita de Marcia establecen un tono cálido y riguroso. | Convertir «conversaciones que cuidan» en un sistema visual recurrente mediante trayectorias, nodos y un recorrido de colaboración. |
| Contenido | Servicios y metodología explican la oferta de forma prudente. | Añadir formatos, entregables y etapas para reducir la incertidumbre de quienes solicitan una colaboración. |
| Conversión | El formulario capta organización, necesidad y canal de respuesta. | Incorporar modalidad, horizonte temporal y tamaño aproximado de equipo para que Marcia pueda preparar una primera respuesta contextualizada. |
| Operación | Las solicitudes se guardan de forma validada en la base de datos. | Preparar una consulta administrativa protegida para leer las solicitudes sin exponer datos al público. |
| Confianza | Se explicitan principios, privacidad y ausencia de testimonios ficticios. | Reforzar el marco de colaboración y mantener huecos exclusivamente para credenciales y voces autorizadas. |

El criterio de decisión es simple: cada ampliación debe aportar **contexto, confianza o capacidad de respuesta**. Se descartarán funcionalidades que impliquen orientación clínica individual, vigilancia de personas atendidas, promesas de impacto o recolección de datos innecesarios.
